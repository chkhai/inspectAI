# InspectAI — Industrial Visual Inspection System

InspectAI არის კომპიუტერული ხედვის (Computer Vision) პროექტი, რომლის მიზანია სამრეწველო დეტალებზე დეფექტების ავტომატური აღმოჩენა და მათი ლოკალიზაცია.

პროექტი ფოკუსირებულია მეტალის ქანჩებზე (Metal Nuts) და იკვლევს ანომალიების აღმოჩენის სხვადასხვა მიდგომას, მათ შორის წინასწარ გაწვრთნილ ნეირონულ ქსელებსა და ნულიდან გაწვრთნილ კონვოლუციურ ავტოენკოდერებს.

## მონაცემთა ნაკრები

გამოყენებულია **MVTec Anomaly Detection (MVTec AD)** მონაცემთა ნაკრების `metal_nut` კატეგორია.

მონაცემები მოიცავს:
- **220 ნორმალურ სურათს** სასწავლო ნაკრებში;
- **115 ტესტურ სურათს**, საიდანაც 22 ნორმალურია და 93 დეფექტური;
- დეფექტების ოთხ ტიპს: `scratch`, `bent`, `color`, `flip`;
- პიქსელურ ნიღბებს (Ground Truth Masks), რომლებიც დეფექტების ადგილმდებარეობას აღნიშნავს.

ყველა სურათის საწყისი გარჩევადობაა 700 × 700 პიქსელი.

მონაცემები ხელმისაწვდომია [MVTec AD-ის ოფიციალურ გვერდზე](https://www.mvtec.com/company/research/datasets/mvtec-ad).

## გამოყენებული მოდელები

პროექტში განხორციელებულია ოთხი მიდგომა:

**1. ResNet18 + KNN (Baseline)**

ImageNet-ზე წინასწარ გაწვრთნილი ResNet18 გამოიყენება სურათებიდან მახასიათებლების ამოსაღებად. ანომალიის ქულა გამოითვლება ტესტური სურათის მახასიათებლებსა და ნორმალური სურათების მახასიათებლებს შორის უახლოესი მეზობლის მანძილით.

**2. PatchCore**

მოდელი იყენებს ResNet18-ის შუალედურ ფენებს ლოკალური მახასიათებლების მისაღებად. ნორმალური სურათების ფრაგმენტებისგან იქმნება მეხსიერების ბანკი, რომელიც მცირდება მიახლოებითი Coreset Sampling-ით.

ტესტირებისას თითოეული ფრაგმენტი შედარებულია ნორმალურ ფრაგმენტებთან, რის შედეგადაც მიიღება სურათის ანომალიის ქულა და დეფექტის სითბური რუკა (Anomaly Heatmap).

**3. Convolutional Autoencoder**

ნულიდან გაწვრთნილი კონვოლუციური Encoder–Decoder არქიტექტურა, რომელიც სწავლობს ნორმალური სურათების აღდგენას. ანომალიების აღმოსაჩენად გამოიყენება საწყის და აღდგენილ სურათებს შორის განსხვავება.

**4. Residual Convolutional Autoencoder**

ავტოენკოდერის მოდიფიცირებული არქიტექტურა, რომელიც იყენებს Residual Connections-ს. ექსპერიმენტის მიზანია შემოწმდეს, რამდენად აუმჯობესებს ნარჩენი კავშირები რეკონსტრუქციის ხარისხსა და ანომალიების აღმოჩენას.

ორივე ავტოენკოდერი გაწვრთნილია ნულიდან, წინასწარ გაწვრთნილი წონების გამოყენების გარეშე.

## ექსპერიმენტების შედეგები

| მოდელი | Image AUROC | Image AP | Pixel AUROC | Pixel AP |
|---|---:|---:|---:|---:|
| ResNet18 + KNN | 0.8109 | 0.9496 | — | — |
| PatchCore | **0.9834** | **0.9962** | **0.9749** | **0.8359** |
| Convolutional Autoencoder | 0.4663 | 0.7660 | 0.7923 | 0.2793 |
| Residual Autoencoder | 0.4027 | 0.7346 | 0.7620 | 0.2306 |

საუკეთესო შედეგი აჩვენა PatchCore-მა.

ექსპერიმენტებმა ასევე აჩვენა, რომ რეკონსტრუქციის დაბალი შეცდომა ყოველთვის არ ნიშნავს ანომალიების აღმოჩენის მაღალ ხარისხს. მიუხედავად იმისა, რომ Residual Autoencoder-მა ჩვეულებრივ ავტოენკოდერთან შედარებით უკეთესი ვალიდაციის MSE მიიღო, მისი ანომალიების აღმოჩენის მაჩვენებლები გაუარესდა.

## სწავლება და შეფასება

სასწავლო ნაკრების 220 ნორმალური სურათი იყოფა შემდეგნაირად:

- 176 სურათი — Training;
- 44 სურათი — Validation.

ვალიდაციის მონაცემები გამოიყენება მოდელის ქცევის შესაფასებლად და ავტოენკოდერების შემთხვევაში Early Stopping-ისთვის.

საბოლოო შეფასება ხორციელდება ოფიციალურ ტესტურ ნაკრებზე. საბოლოო PatchCore-ის მეხსიერების ბანკი აგებულია 220 ნორმალური სასწავლო სურათით.

შეფასების ძირითადი მეტრიკებია Image-level AUROC და Pixel-level AUROC. დამატებით გამოიყენება Average Precision.

ტესტურ მონაცემებზე მიღებული შედეგები გამოყენებული იქნა ექსპერიმენტების ანალიზშიც, ამიტომ ისინი არ წარმოადგენს სრულად დამოუკიდებელ, ბრმა შეფასებას.

## პროექტის გაშვება

რეპოზიტორიის კლონირება:

```bash
git clone https://github.com/chkhai/inspectAI.git
cd inspectAI
```

ვირტუალური გარემოს შექმნა და გააქტიურება:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

დამოკიდებულებების დაყენება:

```bash
python -m pip install -r requirements.txt
```

მონაცემთა ნაკრების `metal_nut` საქაღალდე უნდა განთავსდეს შემდეგ მისამართზე:

```text
data/raw/metal_nut/
```

ექსპერიმენტების გასაშვებად გამოიყენება `notebooks/` საქაღალდეში არსებული Jupyter Notebook ფაილები.

## შეზღუდვები და სამომავლო განვითარება

მონაცემთა ნაკრები შედარებით მცირეა და გადაღებულია კონტროლირებად გარემოში. ამიტომ მიღებული შედეგები ავტომატურად ვერ განზოგადდება სხვა საწარმოო პირობებზე.

შემდგომი სამუშაო მოიცავს შეცდომების ანალიზს, დამატებით ანომალიების აღმოჩენის არქიტექტურებს, ინფერენსის ოპტიმიზაციასა და ინტერაქტიული დემოს შექმნას.
